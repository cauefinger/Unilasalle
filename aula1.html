O que é Hypertext Markup Language (HTML)?

HTML é uma linguagem de marcação usada para criar e estruturar páginas da web, organizando textos, imagens, links e outros elementos.

Como e porquê surgiu o HTML?

O HTML foi criado por Tim Berners-Lee no início da década de 1990 para facilitar a criação e o compartilhamento de documentos pela internet.

O que é eXtensible Hypertext Markup Language (XHTML)?

XHTML é uma versão do HTML baseada nas regras do XML, sendo mais rigorosa na forma como o código deve ser escrito.

Qual a diferença de XHTML para HTML?

O XHTML possui regras de escrita mais rigorosas, enquanto o HTML é mais flexível em sua sintaxe.

O que é eXtensible Markup Language (XML)?

XML é uma linguagem de marcação usada para armazenar, organizar e transportar dados de forma estruturada.

Qual a diferença de HTML para XML?

O HTML é usado principalmente para estruturar páginas da web, enquanto o XML é usado para organizar e transportar dados.
